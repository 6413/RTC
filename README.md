# RTC (Real-Time Clock)

<img width="360" height="503" alt="image" src="https://github.com/user-attachments/assets/43779c5b-ff21-4fcd-9c51-0b25cdf33578" />

**Description:**

- Components have been **hand-soldered**.
- Reads time from the integrated circuit **MCP7940N** ([datasheet](https://www.microchip.com/wwwproducts/en/MCP7940N)).
- Functions as both a **calendar** and a **clock**.
- Time can be adjusted using the **three buttons** on the circuit board.
- Time values are stored and parsed using **binary-coded decimal (BCD)** ([Wikipedia](https://en.wikipedia.org/wiki/Binary-coded_decimal)).
